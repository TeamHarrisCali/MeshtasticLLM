Our radio's position

Click the map to choose where the radio is. Drag to move, scroll or use + / − to zoom. This uses the OpenStreetMap background: this PC downloads the tiles you look at from openstreetmap.org and keeps a copy, so they load quickly next time and work offline.

This writes a fixed position to the radio. The radio then shares it with the mesh on its normal position schedule, so anyone in range can see where it is. It stays until you remove it here.

What the AI can do

Settings stored on the radio

"Pull" reads the radio's settings and saves a backup copy. Change values below, then "Save to the radio" writes only what changed. The settings being replaced are backed up first, and the radio restarts to apply them (the bridge reconnects by itself). Wi-Fi, keys, MQTT credentials and the Bluetooth PIN are never shown or changed here.

Download a model

Downloads come from ollama.com through your local Ollama and can be several GB. The suggestions are just examples; any name from ollama.com/library works. A download can be cancelled and resumed later.

Models side by side

      

      
Each row is the newest run for that model and prompt variant. Development questions are what the prompts were improved against; held-out questions are only ever used to measure, never tuned to, so that score is the honest one. A question counts as right when the model picked the right tool (or rightly none), or answered only from the live facts it was given.

      
To add a model: python eval_tools.py --model llama3.2:3b --variant gated_retry --set heldout --out eval_results/my_run.csv (see the README), then reload this page. It takes several minutes and uses Ollama, so it isn't started from here.
